## 📌 Проект
 
### [playwright-ui-tests](https://github.com/yoqattttt/playwright-ui-tests)
Автотесты для litres.ru на Python + Playwright + pytest.
 
- Архитектура **Page Object Model** — локаторы и действия разделены по классам
- **Параметризация тестов** через JSON-файл с тестовыми данными
- Автоматическая генерация отчётов **Allure**
- **CI** через GitHub Actions — тесты запускаются при каждом пуше
- Автоматический скриншот при падении теста (кастомная pytest-фикстура)
- Устойчивые локаторы (`data-testid`, `get_by_role`) вместо хрупких CSS/XPath
